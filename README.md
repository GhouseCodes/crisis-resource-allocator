# Crisis Resource Allocator

A decision-support dashboard for district-level health resource allocation in India.

Built for Palantir's Build Now challenge.

## What it does
- Scores every district by resource stress (beds per 1000 pop vs disease burden)
- Surfaces prioritized action recommendations for health officers
- Filters by state, disease category, and stress level
- Shows resource gap analysis and 6-month trend

## Data source
Based on NHM (National Health Mission) public district health data patterns, 2024.

## Run it
Download index.html and open in any browser. No server required.
